13 — Intégration

Utiliser le pack dans un projet React

Copiez le dossier design-pack/ dans votre projet (par exemple dans src/design-pack/), puis choisissez l'option qui correspond à votre stack.

A · CSS seul (toute stack)

// main.tsx
import './design-pack/transliate.css';

// n'importe quel composant
<button className="btn btn-primary">Valider</button>
<span className="badge badge-green">Terminée</span>
<div className="card">…</div>

B · Composants React prêts

import { Button, Badge, Field, Input, StatCard }
  from './design-pack/react';

<Field label="E-mail" error={err}>
  <Input type="email" invalid={!!err} />
</Field>
<Button variant="cta">+ Nouvelle commande</Button>

C · Tailwind CSS v3

// tailwind.config.js
import transliate from './src/design-pack/tailwind-preset.js';
export default {
  presets: [transliate],
  content: ['./index.html', './src/**/*.{ts,tsx}'],
};

/* index.css — import EN PREMIER */
@import './design-pack/transliate.css';
@tailwind base; @tailwind components; @tailwind utilities;

D · Tokens JS (graphiques, inline)

import { colors, chartPalette } from './design-pack/tokens';

<Bar dataKey="revenue" fill={colors.primary} />
<Line stroke={chartPalette[1]} />

// ou via CSS variables
style={{ color: 'var(--text-soft)' }}
